# 🍽️ lesson-01 — мобильное приложение для поиска заведений
*Рсай Бексаят, ИС-25-6К, 2- курс.*
## ✨ Возможности

| Раздел | Что умеет |
|---|---|
| **Авторизация** | Вход, регистрация, восстановление пароля по коду, выбор города |
| **Валидация** | Ошибки под полями, маска телефона `+7 (700) 555 77 55`, проверка пароля (8+ символов, заглавные и строчные буквы) |
| **Главная** | Список заведений города, фильтр по категориям, обновление свайпом вниз |
| **Поиск** | Фильтрация по названию и категории по мере ввода |
| **Избранное** | Сердечко на карточке, отдельная вкладка со списком |
| **Детали** | Описание, адрес, телефон, кнопка «Позвонить» |
| **Профиль** | Смена фото из галереи, данные пользователя, выход |
| **Настройки** | Язык (RU / ҚАЗ), тема (системная / светлая / тёмная), смена города, имени и пароля, уведомления |
| **Удобство** | Онбординг при первом запуске, скелетоны загрузки, всплывающие тосты, вибрация, плавные анимации |
| **Сохранение данных** | Аккаунты, избранное, тема и язык хранятся на телефоне и не пропадают после перезапуска |

## 🛠 Технологии

- [React Native](https://reactnative.dev/) 0.86 и [React](https://react.dev/) 19
- [Expo](https://expo.dev/) SDK 57 (запуск через Expo Go)
- TypeScript
- [React Navigation](https://reactnavigation.org/) (native-stack и bottom-tabs)
- AsyncStorage: хранение данных на устройстве
- `@expo/vector-icons`: иконки
- `expo-font` и Manrope: шрифт
- `expo-haptics`: вибрация
- `expo-image-picker`: выбор фото профиля
